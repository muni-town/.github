Muni Town is a [collective of people](https://blog.muni.town/muni-town/) working on Open Social Web ventures in alignment with the [Community OS](https://blog.erlend.sh/assembling-community-os) product vision.

Our primary project is [Roomy](https://github.com/muni-town/roomy), the successor of [Weird](https://github.com/muni-town/weird) (merged with Roomy) and [Commune](https://github.com/commune-sh) (continued as a tightly scoped pivot).
